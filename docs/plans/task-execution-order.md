### 执行顺序（按阶段）

#### 阶段 B1：基础搭建

按顺序执行，有依赖关系：

```
步骤 1  M1-01  EL   Electron 项目初始化
步骤 2  M1-02  BE   Python FastAPI 服务初始化
步骤 3  M1-03  BE   SQLite 数据模型与存储          ← 依赖步骤 2
步骤 4  M1-04  BE   文件存储管理                    ← 依赖步骤 2
步骤 5  M1-05  BE   文件上传 API                    ← 依赖步骤 2、4
```

#### 阶段 B2：核心生成管线

三个任务可并行开发，最终通过 M2-04 集成：

```
步骤 6a  M2-01  BE   Prompt Optimizer 模块          ← 依赖步骤 2、3
步骤 6b  M2-02  BE   素材生成 Engine                ← 依赖步骤 2、3
步骤 6c  M2-03  BE   图像后处理管线                  ← 依赖步骤 2
步骤 7   M2-04  BE   生成 API 路由（集成）           ← 依赖 6a、6b、6c、步骤 5
```

> **⚠️ 联调节点 A：** 步骤 7 完成后通知前端，M2-05 生成页 UI 可以开始对接。

#### 阶段 B2-并行：辅助 API（可与 B2 并行）

不依赖生成管线，有额外人力时可提前做：

```
步骤 8a  M3-04  BE   资产管理 API                    ← 仅依赖步骤 3
步骤 8b  M4-02  BE   项目管理 API                    ← 仅依赖步骤 3
步骤 8c  M5-01  BE   API 配置持久化与测试            ← 仅依赖步骤 2
步骤 8d  M5-02  BE   异常处理规范化                  ← 仅依赖步骤 2
```

> **⚠️ 联调节点 B：** 步骤 8a 完成后通知前端，M3-05 资产库页可以开始对接。
> **⚠️ 联调节点 C：** 步骤 8b 完成后通知前端，M4-05 侧边栏可以开始对接。
> **⚠️ 联调节点 D：** 步骤 8c 完成后通知前端，M5-03 设置页可以开始对接。

#### 阶段 B3：风格与导出

```
步骤 9a  M4-01  BE   风格管理 API + 参考图分析       ← 依赖步骤 3、5
步骤 9b  M3-01  BE   Sprite Sheet 拼接引擎          ← 依赖步骤 6c
步骤 9c  M3-02  BE   Tileset 拼接引擎               ← 依赖步骤 6c
步骤 10  M3-03  BE   导出 API                       ← 依赖步骤 9b、9c
步骤 11  M4-03  BE   复现与变体生成                  ← 依赖步骤 7
```

> **⚠️ 联调节点 E：** 步骤 9a 完成后通知前端，M4-04 风格库 UI 可以开始对接。
> **⚠️ 联调节点 F：** 步骤 10 完成后通知前端，M3-06 导出页可以开始对接。

#### 阶段 B4：打包

```
步骤 12  M5-05  EL   Electron 打包与安装包           ← 依赖步骤 1、全部功能完成
```

### 执行顺序（按阶段）

#### 阶段 F1：基础搭建

```
步骤 1  M1-06  FE   React 项目初始化
步骤 2  M5-04  FE   快捷键 + Toast + ConfirmDialog    ← 依赖步骤 1
```

> 步骤 2 不依赖任何后端 API，可在等后端 B1 完成的同时做。

#### 阶段 F2：核心页面

等待后端联调节点 A（M2-04 就绪）后开始：

```
步骤 3  M2-05  FE   生成页 UI                          ← 依赖 F1 + 联调 A
```

> **这是前端的核心工作。** 步骤 3 完成后，用户可在 UI 上完成完整生成流程。

#### 阶段 F3：资产与风格页面

等待后端联调节点 B（M3-04）、C（M4-02）、E（M4-01）就绪后并行开始：

```
步骤 4a  M3-05  FE   资产库页 UI                       ← 依赖 F1 + 联调 B
步骤 4b  M4-04  FE   风格库 UI                         ← 依赖 F1 + 联调 E
步骤 4c  M4-05  FE   侧边栏 + 项目管理                 ← 依赖 F1 + 联调 C + 步骤 4b
```

> 步骤 4a 和 4b 可并行。步骤 4c 依赖 4b（风格库 UI 是侧边栏的入口）。

#### 阶段 F4：导出与设置

等待后端联调节点 D（M5-01）、F（M3-03）就绪后并行开始：

```
步骤 5a  M3-06  FE   导出页 UI                         ← 依赖 F1 + 联调 F
步骤 5b  M5-03  FE   设置页 UI                         ← 依赖 F1 + 联调 D
```

## 三、联调节点清单

6 个跨线联调节点，后端完成时通知前端：

| 节点 | 后端完成标志 | 前端可启动任务 | 通知方式 |
|------|-------------|--------------|---------|
| **A** | M2-04 生成 API 跑通，curl 可调用 | M2-05 生成页 UI | 后端完成即通知 |
| **B** | M3-04 资产管理 API 跑通 | M3-05 资产库页 UI | 后端完成即通知 |
| **C** | M4-02 项目管理 API 跑通 | M4-05 侧边栏 | 后端完成即通知 |
| **D** | M5-01 设置 API 跑通 | M5-03 设置页 UI | 后端完成即通知 |
| **E** | M4-01 风格 API + 参考图分析跑通 | M4-04 风格库 UI | 后端完成即通知 |
| **F** | M3-03 导出 API 跑通 | M3-06 导出页 UI | 后端完成即通知 |
